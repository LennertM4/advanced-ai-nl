## Schaalformule

`maandkost = kost per run × aantal runs per maand`. Voor de voorbeeldberekening neem ik 100 geclassificeerde berichten per maand: €0,002 per run geeft €0,20 per maand, €2,00 bij 10× en €200 bij 1.000×.

De prijsaanname uit de les is $1 input en $5 output per miljoen tokens, omgerekend met $1 = €0,90. De exacte kost per run moet na één echte run worden ingevuld met het gemeten input- en outputaantal.
